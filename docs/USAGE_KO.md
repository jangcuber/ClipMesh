# ClipMesh 사용 방법

## 처음 연결

1. 첫 기기에서 **새 그룹**을 만들고 **동기화 켜기**를 켭니다. 서버 주소는 입력하지 않아도 됩니다.
2. 기기 ID가 준비되면 **다른 기기에 보여줄 QR**을 엽니다.
3. 새 기기에서 **QR 스캔** 또는 **QR 이미지로 참가**를 선택하고 동기화를 켭니다.
4. 현재 그룹 이름과 **연결된 다른 기기 수**를 확인합니다.

기존에 연결된 어느 기기에서든 새 기기를 초대할 수 있습니다. 최초 연결 시 QR에 포함된 기기 중 하나는 온라인이어야 합니다. QR에는 비밀키가 있으므로 공개 게시하거나 타인에게 보내지 마세요.

## 평소 사용

텍스트나 이미지 픽셀을 복사하면 같은 그룹의 다른 기기 클립보드에 반영됩니다. 파일 경로 복사는 이미지 전송이 아닙니다. 대상 앱이 이미지 붙여넣기를 지원해야 합니다.

- **켜기:** 현재 기기에서 클립보드를 주고받습니다.
- **끄기:** 현재 기기의 송수신을 멈춥니다. 저장된 그룹과 키는 삭제하지 않습니다. Android는 서비스도 종료합니다.
- 여러 그룹을 저장할 수 있지만 한 번에 하나의 활성 그룹만 동기화합니다.
- 꺼져 있던 기기는 재접속한 뒤 최신 값으로 맞춥니다. 오프라인 중의 모든 중간 복사를 전달하는 것은 아닙니다.

## 연결 상태

- **다른 기기 3대:** 이 기기를 제외하고 인증된 상대 연결이 세 개입니다.
- **직접 연결:** 직접 P2P 경로입니다.
- **암호화 릴레이:** 직접 경로가 막혀 대체 경로를 사용합니다. 같은 그룹 안에서도 기기마다 경로가 다를 수 있습니다.
- **기기를 찾는 중:** 아직 상대 연결을 확인하지 못했습니다.

서버 접속이나 저장된 피어 목록만으로 온라인 기기 수를 늘리지 않습니다. 상대가 동기화를 꺼두면 네트워크 연결이 남아 있어도 클립보드를 주고받지 않을 수 있습니다.

## 창 닫기와 자동 실행

| 플랫폼 | 창을 닫으면 | 자동 복구 조건 |
|---|---|---|
| Mac | 메뉴 막대 ⇄에서 계속 실행 | 로그인 자동 실행 사용 |
| Windows | 트레이의 숨겨진 아이콘 ∧에서 계속 실행 | 설치된 로그인 항목 사용, 앱에서 끌 수 있음 |
| 루팅 Android | foreground 알림 서비스 유지 | 저장된 켜짐 상태, 첫 잠금 해제, 배터리·자동 시작 허용 |
| 탈옥 iPhone | SpringBoard 엔진 유지 | 탈옥 tweak injection이 활성화된 상태 |

Mac·Windows의 완전 종료는 메뉴/트레이에서 선택합니다. Android를 강제 종료하거나 제조사 절전 정책이 서비스를 차단하면 직접 실행해야 할 수 있습니다. **탈옥 iPhone은 완전 재부팅 후 탈옥을 다시 활성화해야 할 수 있습니다.**

## 기존 그룹 전환

예전 WebSocket 그룹은 고급 설정에서 **Mac 없이 연결로 전환**하거나, 0.3.0의 새 QR을 같은 그룹으로 다시 가져옵니다. 그룹 키와 저장된 기기 ID는 유지됩니다. 모든 참여 앱을 0.3.0으로 업데이트하세요. 일부 기기가 꺼져 있어도 나머지 온라인 기기끼리는 동기화됩니다.

## 플랫폼 준비

- **Android:** 루팅, Vector/LSPosed의 System Framework 범위, 재부팅, 알림 권한, 배터리 제한 해제가 필요합니다. 상세: [Android 안내](../platforms/android/README.md).
- **iPhone:** rootless 탈옥과 tweak loader가 필요합니다. DEB 설치 후 리스프링합니다. 상세: [iOS 안내](../platforms/ios/README.md).

연결·설치 문제가 있으면 [문제 해결](TROUBLESHOOTING.md)을 참고하세요.
