# 문제 해결

## 연결되지 않음

- 모든 기기에서 같은 그룹과 **동기화 켜짐**을 확인하세요.
- 처음 QR로 연결할 때는 QR에 포함된 기존 기기 중 하나가 온라인이어야 합니다.
- 앱/서비스를 완전히 종료했다면 다시 실행하세요. 네트워크 변경 직후에는 주소 탐색에 시간이 걸릴 수 있습니다.
- 0.3.0 이전 WebSocket 그룹은 고급 설정에서 Mac 없이 연결로 전환하거나 새 QR로 다시 참가합니다.
- 공개 discovery/relay 서비스가 차단되거나 인터넷이 없으면 연결할 수 없습니다. 연결된 피어 수와 경로를 구분해서 확인하세요.

## Windows 업데이트 오류 / already running

현재 설치본은 새 helper를 임시 폴더에서 실행해 기존 설치의 UI/core를 종료하고 파일 잠금을 확인한 후 교체합니다. 파일 쓰기 오류가 나오면 **Ignore/무시** 대신 취소 또는 재시도를 사용하세요. 필요하면 작업 관리자에서 해당 설치의 `ClipMesh.exe`, `clipmesh-core.exe`를 종료한 뒤 다시 설치합니다.

설정과 키는 `%LOCALAPPDATA%\ClipMesh`에 보관됩니다. 복구하려고 앱을 삭제하거나 이 폴더를 지울 필요는 없습니다. 앱을 다시 실행하면 기존 설정 창이 열립니다. 창을 닫아도 트레이에서는 계속 실행됩니다.

## Android 백그라운드 복사가 안 됨

**루팅 + Vector/LSPosed + System Framework (`android`) 범위**를 확인하고 재부팅하세요. 배터리 제한을 풀고 알림 권한을 허용합니다. 앱을 강제 종료했다면 한 번 직접 실행합니다. 일부 Samsung/ROM의 내부 ClipboardService 변경은 호환성 문제를 일으킬 수 있습니다. APK의 최소 Android 버전이 모든 ROM의 후킹 호환성을 의미하지는 않습니다.

## Android QR 화면

카메라 권한을 허용하세요. 카메라를 사용할 수 없으면 **QR 사진 가져오기**로 로컬 이미지를 선택할 수 있습니다. 현재 스캐너는 전용 Activity에서 권한/초기화 오류를 처리합니다. 진단 화면의 오류 클래스와 앱 버전을 공유할 수 있지만 QR 원문이나 스크린샷은 공개하지 마세요.

## iPhone 동작하지 않음

rootless 탈옥 상태와 tweak loader를 확인하세요. DEB 설치/업데이트 후 리스프링하고 첫 잠금을 해제합니다. 일반 재부팅으로 탈옥이 비활성화됐다면 재활성화가 필요할 수 있습니다. 설정 앱을 닫는 것은 엔진 종료가 아닙니다. rootful/roothide나 비탈옥 환경은 지원하지 않습니다.

## 텍스트는 되는데 이미지가 안 됨

모든 앱을 같은 최신 버전으로 업데이트하세요. 파일 경로 대신 이미지 픽셀을 복사하고, 붙여넣을 앱이 이미지를 지원하는지 확인합니다. PNG 최대8MiB/4천만 픽셀을 넘는 이미지는 건너뜁니다. 원본 이미지의 인코딩·메타데이터·애니메이션은 보존되지 않을 수 있습니다.

## 문제 보고

플랫폼/OS/앱 버전, 직접 연결인지 릴레이인지, 재현 절차를 적어주세요. 초대 링크, QR, 그룹 키, 실제 클립보드 내용, 기기 UDID/개인 주소는 제거해 주세요.
