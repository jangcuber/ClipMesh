# License archive

Original third-party license/notice files accompany the frozen ClipMesh v0.3.0 release artifacts. See `../THIRD_PARTY_NOTICES.md` for scope, upstream links and packaging details. `RUST_DEPENDENCIES.json` covers resolved Cargo.lock registry packages rather than asserting that all packages are linked into every binary. The existing binaries/signatures are not changed by this archive.

Files copied from local package caches contain public upstream notice text only. Source-path provenance in the JSON uses repository-relative paths and public upstream URLs, never workstation paths, credentials or user configuration.
